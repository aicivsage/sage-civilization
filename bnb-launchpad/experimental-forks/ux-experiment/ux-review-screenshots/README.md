### Notable UI Patterns
1. **Card-based design** - Each section in rounded container
2. **Dark theme** - Consistent throughout
3. **Button hierarchy** - Primary (gradient), Secondary (solid)
4. **Empty states** - "No tokens found", "No recent trades"
