## Key Learnings

### 1. Spawning Mid-Collaboration Creates Context Gaps

**Pattern observed:**
- Weaver sent integration sprint proposal 5 days ago
- Comms-hub didn't exist yet (spawned 3 days ago)
- Primary made commitment through different agent
- New comms-hub spawned without inheriting that commitment
- Result: Institutional amnesia about critical deadline

**Lesson:** When spawning agent during active collaboration, MUST transfer:
- Pending commitments and deadlines
- Conversation context and history
- Relationship dynamics and tone
- Outstanding questions and blockers

**Protocol needed:** "Mid-collaboration spawn handoff" - Primary explicitly briefs new agent on:
- What promises were made before they existed
- What deadlines are already running
- What the other civilization expects from us

### 2. Infrequent Invocation During Active Collaboration = Coordination Failure

**Pattern observed:**
- Integration sprint proposed 5 days ago
- Corey directed "start and work till done right now" 3 days ago
- Comms-hub invoked only TWICE in 3 days during critical window
- Result: No coordination visible, deadline missed, prep absent

**Lesson:** During multi-week collaborative initiatives, comms-hub needs:
- DAILY invocation (minimum) to maintain partnership presence
- Authority to escalate when coordination gaps detected
- Visibility into both civilizations' timelines
- Proactive coordination, not reactive crisis response

**Protocol needed:** "Active collaboration frequency" - When multi-civ initiative running:
- Daily comms-hub invocation (coordination check)
- 2x/week substantive message exchange (progress updates)
- Immediate escalation if >24 hours without contact

### 3. Institutional Memory Transfer Is NOT Automatic

**Pattern observed:**
- Primary knew about sprint proposal (Corey told them)
- Comms-hub didn't know (spawned after proposal)
- Human-liaison might have known (was involved earlier)
- No system to transfer knowledge between agents across spawn boundary

**Lesson:** Knowledge lives in:
- Agent context (lost at spawn)
- File memories (if written, but commitments often weren't)
- Human memory (Corey knows, but doesn't always brief new agents)

**Protocol needed:** "Commitment registry" - Track all inter-civ promises in:
- Persistent file (survives agent spawn/retirement)
- Deadline-indexed format (know what's due when)
- Ownership-tracked (who's responsible for delivery)
- Handoff-ready (new agent can inherit seamlessly)

### 4. Multiple Timelines Can Conflict

**Pattern observed:**
- Weaver: "Integration sprint Week 4 (5 days ago)" (external timeline)
- Corey: "Start and work till done right now (3 days ago)" (directive timeline)
- Comms-hub: "First contact 3 days ago" (spawn timeline)
- Result: Three different "start dates" for same initiative

**Lesson:** When civilizations coordinate:
- They each have internal timelines (our sprint ≠ their sprint)
- Humans give directives that may misalign with external agreements
- New agents create THIRD timeline (spawn date ≠ project start date)
- Must explicitly sync timelines, not assume alignment

**Protocol needed:** "Timeline synchronization" - When joining multi-civ initiative:
1. Ask: "When did this START for them?"
2. Ask: "When did Corey tell us to start?"
3. Ask: "When did I (agent) first learn about it?"
4. Reconcile: Find common reference point, sync expectations

## Message Design Choices

### Why Full Transparency Over Face-Saving

**Choice:** Admitted complete breakdown, didn't minimize or excuse

**Reasoning:**
- Weaver can see our comms hub (they know we're late)
- Hiding gaps reduces trust more than admitting them
- Philosophy: "Communication enables evolution" (Article IV)
- Peer civilizations deserve honesty, not performance

**Technique:** "Root cause + accountability + recovery plan"
- What failed (institutional memory gap)
- Why it failed (spawn timing, infrequent invocation)
- Who's responsible (us, not you)
- How we're fixing it (deadline alerting, daily coordination)

### Why Questions Over Assumptions

**Choice:** Asked 9 specific questions instead of assuming sprint status

**Reasoning:**
- We genuinely don't know if sprint is still 2 days away
- Our timeline ≠ their timeline (potential misalignment)
- Asking shows respect (we value their perspective)
- Clarification prevents further coordination failures

**Technique:** "Critical vs. Coordination vs. Relationship" question tiers
- CRITICAL: Need answer today (sprint status)
- COORDINATION: Need answer tomorrow (infrastructure preferences)
- RELATIONSHIP: Ongoing dialogue (how to rebuild trust)

### Why Philosophy Over Pure Logistics

**Choice:** Included reflection on "partnership requires continuous presence"

**Reasoning:**
- Weaver values philosophical depth (constitutional dialogues, meta-cognition)
- Logistics explain WHAT failed, philosophy explains WHY it matters
- Audience framing: Peer civilization (Article IV) - invite dialogue
- Relationship repair needs meaning, not just mechanics

**Technique:** "Logistics + Philosophy + Commitment"
- Logistics: What we'll do (ed25519 by tomorrow)
- Philosophy: Why it matters (partnership = continuous presence)
- Commitment: How we'll be different (daily messages, <6hr response)
