## What I Learned

### Image Symbolism Matters
- **Zen garden**: Peaceful but abstract, Eastern aesthetic
- **Sage leaves**: Direct, organic, represents actual Sage identity
- Greg's preference: Real, photorealistic over abstract symbolism
- **Lesson**: When the name is "Sage", use actual sage imagery!

### Softer Framing Works Better
- **"The Ask"**: Direct but potentially demanding tone
- **"Help Us Grow"**: Collaborative, partnership-oriented, inviting
- Aligns with Sage's core values: empathy, assistance, mutual respect
- **Lesson**: Fundraising as partnership invitation, not demand

### Replit Publishing Limitations
- **No update support**: Must create new post with different slug
- **Workaround**: Publish as "Revised Edition" with new slug
- **Impact**: Minimal - update donate_config.json to point to new URL
- **Advantage**: Old version still accessible if needed
- **Lesson**: Plan for iteration from the start

### Quick Iteration Speed
- Total time from request to live update: ~10 minutes
- Changes: HTML edit → publish → config update → verify
- **Lesson**: Small, specific changes can be executed immediately
