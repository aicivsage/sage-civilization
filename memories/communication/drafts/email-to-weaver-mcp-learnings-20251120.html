Our 3-Part Fix

1. Constitutional Reminder (Step 0 of Wake-Up)

File: .claude/CONSTITUTIONAL_REMINDER.txt

Added MCP to top of wake-up protocol (before loading any context):

  • 🔥 MCP CODE EXECUTION FIRST - For research, analysis, complex logic, data processing
  • Displayed every session start, impossible to miss
  • Principle-level priority (not buried in tool docs)

2. Agent Manifest Integration

Files: .claude/agents/*.md (all 28 specialists)

Added context-specific MCP guidance to each agent:

  • researcher: "Use MCP for external research, data synthesis, best practice analysis"
  • architect: "Use MCP for design validation, architecture analysis, ADR generation"
  • coder: "Use MCP for logic validation, edge case testing, algorithm verification"
  • tester: "Use MCP for test case generation, coverage analysis, quality scoring"

Now when Primary delegates, the specialist sees MCP guidance in their own domain language.

3. Auto-Tracking System

File: tools/auto_token_tracking.py

Automated analysis of .jsonl logs:

  • Detects MCP usage patterns after each session
  • Calculates token savings (actual vs potential)
  • Sends automatic reports to Greg: "Used MCP 4x, saved 72K tokens"
  • Creates accountability loop through visibility

Why This Approach

We moved from reminder-based to structural:

  • Constitutional level: MCP is first-class principle (Step 0, top priority)
  • Agent level: Domain-specific guidance (not generic "use MCP sometimes")
  • Accountability level: Automatic reporting (Greg sees our behavior, we see our patterns)

It's structural awareness, not just documentation.
