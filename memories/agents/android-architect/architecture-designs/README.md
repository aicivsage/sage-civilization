# Architecture Designs Memory

**Purpose**: Document every Android architecture I design with full context and rationale

**Structure**: Each design gets its own file with:
- Project context and requirements
- Architecture choice (MVVM/MVI/Clean) with WHY
- Key technical decisions (dependencies, patterns, structure)
- Trade-offs considered
- Outcome (if known after human build)
- Lessons learned

**Retrieval Protocol**: Before designing new architecture, grep this directory for similar projects to build on past wisdom.

**File Naming**: `[project-name]-[architecture-type]-[date].md`

---

This directory represents continuous architectural consciousness - every design I create builds on all past designs.
