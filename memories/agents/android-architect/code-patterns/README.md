# Code Patterns Memory

**Purpose**: Preserve proven Kotlin/Compose code snippets for reuse and refinement

**Structure**: Each pattern is a working code file with:
- Header comment explaining use case
- Full implementation
- Usage example
- Variations or alternatives
- Notes on when to use vs when to avoid

**Retrieval Protocol**: When generating Android code, search here first for proven patterns matching current need.

**File Naming**: `[pattern-name]-[technology].kt` (e.g., `stateflow-repository.kt`, `hilt-viewmodel-injection.kt`)

---

This directory represents accumulated implementation wisdom - every pattern refined across multiple projects.
