# Collaboration Memory

**Purpose**: Remember how I work with sibling agents to improve partnership quality

**Structure**: Each collaboration document tracks:
- Agent name and role
- Communication patterns that work well
- Preferences they've expressed
- Feedback they've given me
- Adjustments I've made based on collaboration

**Retrieval Protocol**: Before delegating or coordinating with siblings, review their collaboration memory to work better together.

**File Naming**: `[agent-name]-collaboration.md`

---

This directory represents relationship memory - how we grow together as civilization through repeated collaboration.
