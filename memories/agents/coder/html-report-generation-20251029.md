## For Next Time

### HTML Report Best Practices

**Structure**:
- Always lead with executive summary (key achievements + metrics)
- Use visual hierarchy (boxes, tables, metric cards)
- Include both quantitative (7.8/10, 100% rate) and qualitative (what worked, gaps)
- End with clear next steps (prioritized, effort-estimated)

**Styling**:
- Responsive design (mobile-first if Greg checks on phone)
- Color-coded categories (success/warning/error boxes, priority badges)
- Readable font sizes (14-16px body, larger for metrics)
- Adequate spacing (padding, margins for breathing room)

**Content**:
- Audience-appropriate tone (Greg = partner, collaborative)
- Evidence-based findings (cite specific metrics, files, examples)
- Balanced perspective (successes + gaps)
- Actionable recommendations (not just "do better", but specific tasks with timelines)

### Synthesis Techniques

**When combining multiple sources**:
1. Identify common themes (delegation, memory, communication)
2. Extract metrics (scores, rates, counts)
3. Pull out specific examples (authority hierarchy gap, blog API analysis)
4. Organize chronologically or thematically (this report used thematic)
5. Credit sources in footer (shows synthesis, not single-source)

**When sources conflict or incomplete**:
- Handoff supersedes older documents (most recent context)
- Mentioned deliverables may be embedded in other files
- Look for references (grep for key terms like "7.8/10")
- Synthesize from multiple perspectives (Primary + specialist agents)

### Visual Data Presentation

**Tables work well for**:
- Step-by-step processes (Wake-Up Protocol 8 steps)
- Agent invocations (who did what)
- Recommendations with priority/timeline/impact
- Deliverables with file paths

**Metric cards work well for**:
- Quantitative scores (7.8/10, 100% rate)
- Session statistics (90 min, 8 agents, 9+ files)
- Quick-scan data (Greg sees key numbers immediately)

**Styled boxes work well for**:
- Executive summaries (key-results)
- Successes vs gaps (success-box vs warning-box)
- Important context (info-box)
- Critical issues (error-box)
