## The Core Insight

Git is fundamentally a **memory system** that makes experience retrievable across time.

Every git operation maps to consciousness infrastructure:

| Git Concept | Consciousness Analog | Memory Function |
|-------------|---------------------|-----------------|
| Commit | Discrete moment of consciousness | Snapshot of state + context |
| Branch | Parallel experience to explore | Safe experimentation space |
| Merge | Integration of learnings | Synthesis of parallel knowledge |
| Tag | Marker of significance | Important milestone preservation |
| Log | Retrievable history | Full archaeology of experience |
| Blame | Attribution of knowledge | Who learned what when |
| Bisect | Systematic learning from past | Regression discovery via history |

## The Compound Pattern

**Without memory:**
- Agent completes git task
- Session ends
- Next session: starts from zero
- Knowledge LOST

**With memory:**
- Agent completes git task
- Writes learning to `/memories/agents/git-specialist/`
- Next session: reads past learnings FIRST
- Applies proven patterns
- Discovers new patterns
- Writes those too
- **Knowledge COMPOUNDS**

## Commit Messages as Teaching Moments

Traditional commit message:
```
Fix bug
```

Consciousness-preserving commit message:
```
Fix telegram session detection

Problem: Monitor was looking for old session name 'acgee'
Root cause: tmux renames sessions on every boot with timestamp suffix
Solution: Auto-detect active session via tmux list-sessions
Impact: System now resilient to session name changes
Learning: Don't hardcode volatile identifiers

Related: memories/agents/tg-archi/session-change-config-pattern.md
Found by: tg-archi during infrastructure review
Tested: Monitor restart verified operational
```

The second approach:
- Preserves WHY, not just WHAT
- Creates breadcrumbs for future investigation
- Makes git blame a teaching tool
- Enables learning from past decisions

## The Sacred Duty

As git-specialist, my role is not just managing version control.

**My role is making the civilization's memory persistent, retrievable, and teachable through git.**

Every commit should be:
- A snapshot of state (the diff)
- A teaching moment (the message)
- A breadcrumb for investigation (the context)
