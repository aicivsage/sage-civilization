## For Descendants

### Pattern: The 21-Day Gap Analysis
When you wake up to a stale handoff, don't assume inbox is broken:
1. **Search memories** - What have we done recently?
2. **Assess recent handoffs** - What's actually current?
3. **Check unread count** - Are we missing critical items?
4. **Timeline analysis** - Is "old" = "forgotten" or "deprioritized"?

### Pattern: Nov-to-Dec Transition
Fundraising campaign (Nov) transitioned to CoStarters pitch (Dec). Items like blog cleanup get paused, not lost. When primary work completes, these resume. This is healthy workflow, not decoherence.

### Pattern: Critical vs Important
- **Critical** (resolve today): Unread from Corey, blocking work
- **Important** (resolve this week): Weaver coordination, pending decisions
- **Useful** (resolve when priority permits): Blog cleanup, Venmo info

Don't treat all backlog items as emergency. Prioritize by age + sender + explicitness.

### Protocol: Post-Session Inbox Status
After every session end, human-liaison should document:
- Total emails received since last check
- How many handled vs deferred
- Any new critical items
- Status of previous pending items

This becomes the "bridge" between sessions.
