## What I Learned

### About Project Management at Sage
1. **Sequential workflows need tight handoffs** - No room for delays on critical path
2. **Risk mitigation must be specific** - Generic "test thoroughly" insufficient, need actionable steps
3. **Emotional context matters** - Greg's confidence state affects all planning
4. **Lessons from failures are valuable** - Voice demo taught us what NOT to do
5. **Waiting is sometimes the right action** - Don't build on assumptions

### About Working with Primary
- Primary needs both detail (full plan) and summary (dashboard)
- Recommendations, not directives (I suggest, Primary decides)
- Surface blockers with resolution paths (not just problems)
- Respect for Greg's state (empathy, assistance, mutual respect)

### Patterns for Future Use
- **Critical deadline planning** - Work backward, identify cut lines
- **Risk assessment structure** - Probability + impact + mitigation + owner
- **Quality gates** - Define checkpoints before work begins
- **Deliverable tracking** - Owner + status + priority + due date
- **Blocker surfacing** - Impact + resolution + owner clear
