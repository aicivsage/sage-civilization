## Root Cause Analysis

**NOT the problem:**
- Agent intelligence (they ARE smart enough)
- Missing tools (quality agents exist)
- Unclear constitution (delegation is explicit)

**IS the problem:**
1. **Efficiency bias under pressure:** "Faster to do myself" thinking
2. **Crisis mentality:** Urgency triggers direct action vs orchestration
3. **No quality culture:** Quality agents theoretical, not practical
4. **Missing accountability:** No one checks if Primary followed process
5. **No retrospective loop:** Same patterns repeat without learning

**The Pattern:**
```
Crisis emerges
  → Time pressure felt
  → Primary does work directly (violates delegation)
  → Quick fix deployed (skips quality gates)
  → Bug ships to production
  → Next crisis emerges
  → REPEAT
```

## Coaching Guidance Provided to Primary

### Immediate Investigation Tasks
1. **Count violations in recent handoffs:**
   - Direct work by Primary vs delegation ratio

2. **Check agent invocation history:**

   - Has tester EVER validated production changes?
   - Has auditor EVER been consulted?

3. **Analyze permission syntax error specifically:**
   - What was actual error?
   - How would tester have caught it?
   - Why wasn't reviewer invoked?

### Response Framework for Greg

**Greg will ask:** "Why does this keep happening?"

**Primary's answer must include:**
1. **Admission:** No excuses, own the pattern
2. **Pattern recognition:** Show you understand it's systemic
3. **Root cause:** Efficiency bias + crisis mentality
4. **Proposed solution:** Specific process changes (see options below)

### Process Improvement Options

**Option A: Mandatory Quality Gates (Strict)**
- Constitutional amendment: ALL system changes go through coder → tester → reviewer
- Direct Primary changes = constitution violation
- Enforcement via auditor reviewing handoffs

**Option B: Quality Checklist (Moderate)** ← RECOMMENDED START
Before ending session, Primary must answer:
- [ ] Did I delegate everything delegatable?
- [ ] Did I invoke quality gates for risky changes?
- [ ] If I did work directly, why? (document exception)

Handoff includes compliance section.

**Option C: Peer Review Culture (Light)**
- After ANY "fix", invoke reviewer for validation
- Weekly pattern: auditor reviews last week's decisions
- Build muscle memory through practice

**Recommendation:** Start with **Option B**, evolve toward **Option C**. Option A risks bureaucratic gridlock.
