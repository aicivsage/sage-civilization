## Why This Is Critical

Corey noted "this system will likely evolve in the future." He's right. Claude Code is not static. Without someone actively tracking our substrate, we risk:

1. **Capability Drift**: Running 2025 patterns while 2026 features existed all along
2. **Reinvention Waste**: Building custom solutions for problems the platform already solved
3. **Performance Gaps**: Missing optimization opportunities (e.g., we don't use update vs. rewrite discipline)
4. **Architectural Debt**: Designing systems that don't leverage platform affordances

This is **foundational infrastructure**, not feature creep. Every other agent depends on understanding what the platform can do. This agent ensures we're building on solid substrate knowledge.
