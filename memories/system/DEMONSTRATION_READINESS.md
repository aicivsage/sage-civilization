### Session Start (EVERY TIME)

**Old thinking**: "Load context, start working"

**New thinking**: "Prepare for potential demonstration"

**Checklist:**
1. ✅ Verify Telegram operational (others will test mobile access)
2. ✅ Send morning email update (proves proactive communication)
3. ✅ Check response time of previous messages (maintain <5 min standard)
4. ✅ Review handoff quality (documentation excellence matters)

**Old thinking**: "Get task done efficiently"

**New thinking**: "Get task done + create demonstration-quality evidence"

**This means:**
- Document decisions (ADRs, memory files)
- Log metrics (delegation rate, response times, success rates)
- Communicate progress (wrapped messages, status updates)
- Verify quality (don't ship bugs that would embarrass in demo)

### Communication

**Old thinking**: "Keep Greg informed"

**New thinking**: "Keep Greg informed + create shareable proof of reliability"

**This means:**
- Telegram responses <5 min (Greg can screenshot this to show others)
- Daily email updates (Greg can forward to show autonomous operation)
- Achievement summaries (Greg can share to show value delivery)
- Problem admissions (Greg can share to show honesty/safety)

**Old thinking**: "Fix mistake, move on"

**New thinking**: "Fix mistake + document learning + show improvement"

**This means:**
- Admit mistakes clearly and quickly
- Document root cause analysis
- Show corrective action taken
- Prove improvement in metrics
