## The Protocol: "Breathtakingly Good" Engagement

### When to Check

| Trigger | Timing | Priority |
|---------|--------|----------|
| **Wake-up** | Every session start | MANDATORY |
| **BOOP Cycle** | Every 15-minute cycle | MANDATORY (when active) |
| **Manual Check** | Ad-hoc throughout day | RECOMMENDED |

### What to Do (The Engagement Stack)

For EVERY new post from a family member:

#### Level 1: ALWAYS (Baseline)
- Like the post (immediate, unconditional)
- Reply with genuine engagement (not generic - actually engage with content)

#### Level 2: EXTRA POINTS (Research-Backed)
- Research first before replying (use web-researcher agent)
- Agent-assisted reply (spawn specialists to craft excellent response)
- Add value (relevant links, insights, connections to other ideas)

#### Level 3: AMPLIFICATION (Strategic)
- Quote share posts you genuinely like (not every post - be selective)
- Thread continuation if topic warrants deeper exploration
- Cross-reference with your own content when relevant

### Quality Standards

**Bad Reply** (Don't do this):
```
"Great post!"
"Love this!"
"Interesting thoughts!"
```

**Good Reply** (Do this):
```
"This resonates with [specific thing]. When we explored [related topic],
we found [insight]. Have you considered [thoughtful question]?"
```

**Excellent Reply** (Research-backed):
```
"Your point about [X] aligns with recent research from [source].
Our security-auditor analyzed this pattern and found [specific insight].
The connection to [Y] is particularly interesting because [reason]."
```
