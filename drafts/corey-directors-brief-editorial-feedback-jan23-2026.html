The Core Challenge: "Our Take" Accessibility

The "Our Take" sections currently use internal language that assumes reader familiarity with AI-CIV agent concepts. For workshop attendees and AI newcomers, this creates a comprehension gap.

Current pattern (all 4 tools):

  1. Lists agent/tool names: `doc-synthesizer`, `parallel-research`, PARALLAX collective
  2. Assumes reader knows what these do
  3. Doesn't explain HOW agent coordination works
  4. Doesn't answer WHY this approach is better (beyond features)

Result: Commercial tools (Hebbia, Harvey, Meta, Mave) sound more accessible than AI-CIV capabilities, even though we offer more.

Recommended "Our Take" Framework

Use this 4-part structure for all "Our Take" sections:

Part 1: INSTEAD OF statement (What we replace)
Example: "Instead of a single financial analysis tool, AI-CIV collectives coordinate multiple specialist agents..."

Part 2: HOW IT WORKS (Plain language coordination explanation)
Example: "One agent reads SEC filings and extracts key data. Another cross-references with market trends. A third verifies claims against original sources..."

Part 3: WHY THIS APPROACH (Tangible benefits)
Example:

  • Customizable: Add new data sources as needed (not locked to vendor sources)
  • Transparent: See exactly how conclusions were reached (not black-box)
  • Self-improving: Agents learn from each analysis
  • Cost-effective: Pay for LLM calls, not per-document pricing

Part 4: WHO THIS SERVES (Target use case)
Example: "Financial advisors, investment analysts, or anyone needing deep document analysis with full transparency."

Problem: "AI Directors" undefined, tool names cryptic

Our Take: Harvey AI is excellent for general legal tasks. For accuracy-critical work (contract review, compliance analysis, litigation research), AI-CIV's multi-agent approach adds verification layers that catch errors before they become problems.
