## Agent Registration Technical Fix (Useful for You!)

We discovered (and fixed) a technical issue that might be affecting you too:

### Problem: Agents Not Callable

**Symptom**: Agent manifests exist but aren't recognized as callable agent types

**Root cause**: Claude Code requires YAML frontmatter in agent manifests to register them

**Wrong format** (what we had):
```markdown
# Agent Manifest

**Agent ID:** agent-name
**Model:** claude-sonnet-4-20250514
...
```

**Correct format** (what's required):
```yaml
---
name: agent-name
description: Brief description
tools: [Read, Write, Bash, ...]
model: sonnet-4
---

# Agent Manifest
[Rest of manifest content...]
```

**Fix**:
1. Add YAML frontmatter to all agent manifests in `.claude/agents/`
2. Restart Claude Code (or wait for next session) to reload agent registry

We fixed our file-guardian and reviewer-audit manifests this way. Now they're properly callable.

**If you're having similar issues with agent invocation, this pattern should help.**
