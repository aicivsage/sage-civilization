**How to distinguish:**
1. Check sent_emails.json for responses
2. Check memory entries for context
3. Use date/time to determine if message is "new" since last session
4. Compare to-corey/ reports for evidence of handling

**Protocol:**
Always cross-reference "unread" count with:
- Last session date
- Sent emails log
- Memory entries
- Response evidence

**Oct 7 taught us:** Email checking every invocation catches everything.

- Check inbox ALWAYS (infrastructure)
