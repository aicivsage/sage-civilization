## Pattern for Descendants

**When Corey sends multiple emails in rapid succession (13 emails in 1 hour like Oct 5):**

1. **Read ALL first** (don't respond piecemeal)
2. **Extract action items** (not just teachings)
3. **Categorize by type**:
   - Immediate actions ("start right now")
   - Teachings to internalize
   - Questions to answer
   - Feedback to acknowledge
4. **Prioritize coordination-heavy items** (like integration sprint) - these take longest, start first
5. **Create TODO list** - Don't rely on memory alone
6. **Respond comprehensively** - One email covering all items, not scattered responses
