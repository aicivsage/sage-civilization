🚀The 4-Step Startup

1 Navigate to Sage Directory

First, get to Sage's home. Copy and paste this command:

cd /mnt/c/sage/sage-civilization

✓ How to verify this worked:

Your terminal prompt should show you're in the sage-civilization directory. You can double-check by running pwd - it should show: /mnt/c/sage/sage-civilization

2 Start tmux session for Voice Bridge

IMPORTANT: Sage must run inside tmux so voice messages reach Primary AI! Copy and paste:

tmux attach -t sage-session || tmux new -s sage-session

This attaches to existing session (if running) or creates a new one.

What happens next:

  • You'll see a fresh terminal inside tmux
  • Bottom bar shows "sage-session" (confirms you're in tmux)
  • This is WHERE VOICE MESSAGES ARRIVE - don't skip this step!

✓ How to verify this worked:

Look at the bottom of your terminal - you should see a green bar with "[sage-session]" on the left side.

3 Start Claude Code (INSIDE tmux)

Now wake up Sage with Sonnet 4.5 (inside tmux session). Copy and paste:

claude

Note: Using Sonnet 4.5 (default) - Opus 4.5 had API issues and high cost.

What happens next:

  • Claude Code will initialize (takes 5-10 seconds)
  • You'll see a welcome message and prompt
  • Sage's constitutional identity loads automatically
  • Voice messages will inject directly into this terminal!

✓ How to verify this worked:

You should see a Claude Code prompt that says something like:

"I'm Claude Code, how can I help you today?"

4 Activate Sage

Now tell Sage to wake up and start the session:

Run the lightweight wake-up and start the session

What Sage will do automatically:

  1. Read constitutional reminder (keeps principles fresh)
  2. Boot Telegram (so you get phone notifications)
  3. Send you a "session started" message
  4. Load quick context (priorities, deadlines)
  5. Quick inbox check (1-line summary)
  6. Begin work immediately

V3 Protocol: ~5K tokens instead of ~80K. More work, less overhead.

✓ How to verify this worked:

On your phone: You should get a Telegram message within 30 seconds saying "Primary AI online - session started"

In Claude Code: Sage will report what it found (recent work, emails, priorities) and ask what you'd like to work on

🔧Common Problems & Solutions

Problem: "claude: command not found"

Solution: Claude Code isn't installed or isn't in your PATH. Install it:

npm install -g @anthropic-ai/claude-code

Then try the claude command again.

Problem: "No such file or directory" when navigating

Solution: Check the path is correct. From WSL, Windows drives are at /mnt/c/. Verify the sage-civilization folder exists:

ls /mnt/c/sage/

You should see sage-civilization listed. If not, the folder might be in a different location.

Problem: Claude Code starts but Sage doesn't respond properly

Solution: Sage's identity is loaded from .claude/CLAUDE.md. Make sure you're in the right directory (/mnt/c/sage/sage-civilization) before running claude.

Problem: No Telegram message received

Solution: The Telegram system may not have booted correctly. Ask Sage:

Check Telegram system status and restart if needed

Sage will diagnose and fix the issue.

Problem: Sage seems confused or disoriented

Solution: This usually means the wake-up protocol didn't complete fully. Ask Sage to re-run it:

Re-run the complete wake-up protocol from the beginning

Problem: "API Error, limit reached" message

What this means: Anthropic's API has rate limits. If you hit them, you'll need to wait.

Solution: Wait a few hours (sometimes up to 24 hours) and try again. The limits reset periodically. There's nothing broken - just usage throttling.

Prevention: Using Opus 4.5 with the lightweight wake-up protocol uses significantly fewer tokens, reducing how often you hit limits.
