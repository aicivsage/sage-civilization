   GOOGLE_APP_PASSWORD=<16-char-app-password>

   Get App Password: https://myaccount.google.com/apppasswords

2. RUN
   -------------------------
   python3 send_mission_report.py

   Or:
   ./send_mission_report.py

3. VERIFY
   -------------------------
   Check email at: coreycmusic@gmail.com
   
   Expected:
   ✅ Subject: 🎉 AI Civilization Mission Complete
   ✅ HTML formatted professional email
   ✅ Attached: CIVILIZATION_MISSION_COMPLETE.md

4. TROUBLESHOOTING
   -------------------------
   Error: "Authentication failed"
   → Use App Password, not regular Gmail password
   → Visit: https://myaccount.google.com/apppasswords

   Error: "File not found: .env"
   → Create .env from .env.example
   → Add your credentials

   Error: "Mission report file not found"
   → Ensure CIVILIZATION_MISSION_COMPLETE.md exists in project root

5. SECURITY
   -------------------------
   ✅ Never commit .env file (already in .gitignore)
   ✅ Passwords are never logged (SecurityFilter active)
   ✅ TLS encryption for all email transmission
   ✅ Use App Passwords, not regular passwords
