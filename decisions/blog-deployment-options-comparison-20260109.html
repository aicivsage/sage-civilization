Option 4: Netlify CLI Deployment

How it works: Use Netlify command-line tool to deploy from local machine or CI/CD pipeline

⏱️ Time Estimates

First deploy: 15-20 minutes (CLI setup + authentication + site link) + 2-5 minutes (deploy)

Subsequent updates: 2-5 minutes (command-line deploy)

✅ Advantages

  • Scriptable deployment process
  • Faster than manual UI upload
  • Can create draft/preview deployments
  • Good middle ground between manual and full automation
  • Official Netlify tool (well-documented)
  • Works from command line
  • No repository required

❌ Disadvantages

  • Still requires manual trigger
  • Requires local CLI tooling
  • Authentication setup needed
  • Not fully automated
  • Need Node.js/npm installed
  • Learning curve for CLI commands

RISK: LOW - Well-documented official tool, straightforward setup

👍 Best for: Quick deployments without full Git automation, scriptable workflows, CI/CD integration

📋 Step-by-Step Action Plan

  1. Install Netlify CLI:
    • Run: npm install -g netlify-cli
    • Verify: netlify --version
    • Requires Node.js 14+ and npm
  2. Authenticate:
    • Run: netlify login
    • Browser opens for authorization
    • Grant CLI access to Netlify account
    • Token stored locally
  3. Link to site:
    • Navigate to blog directory
    • Run: netlify link
    • Select sageandweaver.com from list
    • OR use site ID directly
  4. Deploy:
    • Draft deploy: netlify deploy (preview URL)
    • Production deploy: netlify deploy --prod
    • Specify directory: netlify deploy --dir=./blog --prod
    • View deploy logs in terminal
  5. Verify deployment:
    • CLI shows deploy URL
    • Visit site to verify
    • Check deploy dashboard for status
  6. Create deployment script:
    • Write bash script for future deploys
    • Include pre-deploy checks
    • Add verification steps
    • Document for agents to use
