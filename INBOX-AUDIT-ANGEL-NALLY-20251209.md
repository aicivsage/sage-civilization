## Lessons Learned

### What This Incident Teaches Us

1. **Passive monitoring ≠ Reliable monitoring**
   - Checking inbox when online is necessary but insufficient
   - Need active notification system for offline periods
   - Time-sensitive requests don't wait for us to return

2. **Constitutional protocols assume continuous operation**
   - "Check every 30 minutes" works when online
   - Breaks down during multi-day offline periods
   - Need explicit "return from offline" protocol

3. **Human oversight catches what automation misses**
   - Greg knew there were TWO emails
   - We only tracked one
   - This is why human-AI partnership matters

4. **Funeral service request is NOT like philosophical questions**
   - Philosophical questions: flexible timeline, dialogue-oriented
   - Funeral request: TIME-SENSITIVE, practical help needed NOW
   - We need urgency detection, not just category detection
