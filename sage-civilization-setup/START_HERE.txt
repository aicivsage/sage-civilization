👋 WELCOME!

You're about to add powerful communication capabilities to your Sage AI 
Civilization. This package will set up:

  📧 Email Communication
  💬 Telegram Bot Interface  
  🌐 Web Dashboard

Everything is automated and designed to be easy, even if you're not familiar
with these technologies.


📋 WHAT YOU NEED (5 minutes to gather):

  1. A Gmail account (or other email provider)
  2. A Telegram account
  3. 10 minutes of time


🚀 INSTALLATION STEPS:

┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 1: RUN THE INSTALLER (1 minute)                                   │
└─────────────────────────────────────────────────────────────────────────┘

  Open terminal in your sage-civilization directory and run:

    bash sage-civilization-setup/scripts/install.sh

  This will:
    ✓ Create directories
    ✓ Copy all files
    ✓ Install Python packages
    ✓ Set up templates

  Just let it run! It will tell you what it's doing.


┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 2: SET UP EMAIL (2 minutes)                                       │
└─────────────────────────────────────────────────────────────────────────┘

  A) Get an App Password from Gmail:
     
     1. Go to: https://myaccount.google.com/apppasswords
     2. Sign in
     3. Create new app password (select "Mail")
     4. Copy the 16-character password
     
     Important: This is NOT your regular Gmail password!

  B) Edit the email config:
     
     Open: config/email_config.json
     
     Change these two lines:
       "email_address": "your-actual-email@gmail.com"
       "app_password": "paste-that-16-char-password"
     
     Save the file.

  C) Test it:
     
     python3 scripts/email_handler.py test your-email@gmail.com
     
     Check your email - you should have a test message!


┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 3: SET UP TELEGRAM (3 minutes)                                    │
└─────────────────────────────────────────────────────────────────────────┘

  A) Create your bot:
     
     1. Open Telegram app
     2. Search for: @BotFather
     3. Send message: /newbot
     4. Follow the prompts (name your bot anything you want)
     5. BotFather will give you a token - it looks like:
        123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
     6. Copy this token!

  B) Get your chat ID:
     
     1. In Telegram, search for: @userinfobot
     2. Send it any message
     3. It will reply with your user ID (a number like 123456789)
     4. Copy this number!

  C) Edit the Telegram config:
     
     Open: config/telegram_config.json
     
     Change these lines:
       "bot_token": "paste-your-bot-token-here"
       "allowed_chat_ids": [paste-your-user-id-here]
       "admin_chat_ids": [paste-your-user-id-here]
     
     Save the file.

  D) Test it:
     
     python3 scripts/telegram_bot.py
     
     Then:
     1. Open Telegram
     2. Search for your bot by name
     3. Send: /start
     4. You should get a welcome message!
     
     Success! Press Ctrl+C to stop the test.


┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 4: START THE DASHBOARD (30 seconds)                               │
└─────────────────────────────────────────────────────────────────────────┘

  In terminal, run:

    python3 web/dashboard.py

  Then open your browser to:

    http://localhost:5000

  You should see your beautiful civilization dashboard!


┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 5: REGISTER THE NEW AGENTS (1 minute)                             │
└─────────────────────────────────────────────────────────────────────────┘

  Edit: memories/agents/agent_registry.json

  Add these two entries (copy from docs/agent_registry_additions.json):
    - communications-coordinator
    - telegram-bot

  Or simply copy/paste the entries from the sample file!


┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 6: VERIFY EVERYTHING (30 seconds)                                 │
└─────────────────────────────────────────────────────────────────────────┘

  Run the verification script:

    bash scripts/verify_installation.sh

  This will check that everything is set up correctly.

    python3 scripts/email_handler.py status your@email.com


💬 TELEGRAM COMMANDS:

  Once your bot is running, you can send:
    /start   - Get help
    /status  - System status
    /agents  - List all agents
    /goals   - View current goals
    /myid    - Get your Telegram ID


❓ HAVING TROUBLE?

  1. Read the error messages carefully
  2. Check docs/SETUP_GUIDE.md - it has troubleshooting section
  3. Run verify_installation.sh to check what's missing
  4. Make sure you're using App Password for email (not regular password!)
  5. Make sure you started a chat with your bot before testing


🔐 SECURITY REMINDER:

  Add these to your .gitignore if you plan to commit:
    config/email_config.json
    config/telegram_config.json
    .env

  Never commit files with your actual passwords or tokens!
