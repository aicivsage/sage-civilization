║                         DATA FLOW EXAMPLE                                 ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  1. User sends message via Telegram: "What's the system status?"         ║
║     │                                                                     ║
║  2. Telegram Bot receives message                                        ║
║     │                                                                     ║
║  3. Bot forwards to Communications Coordinator                           ║
║     │                                                                     ║
║  4. Coordinator routes to Auditor Agent via Message Bus                  ║
║     │                                                                     ║
║  5. Auditor generates status report                                      ║
║     │                                                                     ║
║  6. Report sent back through Message Bus                                 ║
║     │                                                                     ║
║  7. Coordinator formats for Telegram                                     ║
║     │                                                                     ║
║  8. Telegram Bot sends formatted response to user                        ║
║     │                                                                     ║
║  9. All interactions logged in memories/communication/                   ║
║                                                                           ║
