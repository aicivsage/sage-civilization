║  TROUBLESHOOTING                                                  ║
╠═══════════════════════════════════════════════════════════════════╣
║                                                                   ║
║  Email not working?                                               ║
║    ✓ Use App Password, not regular password                       ║
║    ✓ Check smtp.gmail.com port 587                               ║
║    ✓ Enable 2FA to get App Password                              ║
║                                                                   ║
║  Telegram not responding?                                         ║
║    ✓ Start a chat with your bot first                            ║
║    ✓ Verify token is correct                                     ║
║    ✓ Check your user ID is in allowed_chat_ids                   ║
║                                                                   ║
║  Dashboard not loading?                                           ║
║    ✓ Check memories/ directory exists                            ║
║    ✓ Try different port: DASHBOARD_PORT=8080                      ║
║    ✓ Check if port 5000 is in use: lsof -i :5000               ║
