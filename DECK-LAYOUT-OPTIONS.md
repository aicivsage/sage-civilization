# Pitch Deck Layout Options (Zero Text Overlap)

## Option 1: Split Screen (Side-by-Side)

```
┌─────────────┬─────────────┐
│             │             │
│   IMAGE     │    TEXT     │
│   (Full     │   (All      │
│   Height)   │   Content)  │
│             │             │
└─────────────┴─────────────┘
```

**Description:**
- Image on LEFT side (50% of screen width)
- Text on RIGHT side (50% of screen width)
- Both visible simultaneously
- ZERO overlap

**Pros:**
- Clean separation
- Image and text both fully visible
- Professional presentation style

**Example:**
Image fills the entire left half of screen, text fills the entire right half

---

## Option 2: Stacked (Image Top, Text Bottom)

```
┌───────────────────────────┐
│                           │
│         IMAGE             │
│      (Upper 60-70%)       │
│                           │
├───────────────────────────┤
│       TEXT AREA           │
│    (Lower 30-40%)         │
│   (Solid Background)      │
└───────────────────────────┘
```

**Description:**
- Image in UPPER portion (60-70% of screen height)
- Text in LOWER portion (30-40% of screen height) with solid background
- ZERO overlap

**Pros:**
- Full-width image
- Clear separation between image and text
- Image gets more space

**Example:**
Image fills top 2/3 of screen, text area with solid background in bottom 1/3

---

## Option 3: Sidebar + Full Bleed Image

```
┌──────────────────┬────────┐
│                  │        │
│   FULL IMAGE     │  TEXT  │
│   (Background)   │  BAR   │
│                  │ (Solid)│
│                  │        │
└──────────────────┴────────┘
```

**Description:**
- Image fills ENTIRE screen as background
- Solid sidebar on RIGHT (20-25% width) with all text
- ZERO overlap on main image content

**Pros:**
- Maximum image impact
- Text completely separate in solid-color bar
- Modern presentation style

**Example:**
Image is full-screen background, text in solid sidebar on right edge

---

## My Recommendation

**Option 2 (Stacked)** would work best because:
- Images get 60-70% of screen (still prominent)
- Text area is clean and readable (30-40% with solid background)
- Natural reading flow (top to bottom)
- Works well with all 6 slide images
