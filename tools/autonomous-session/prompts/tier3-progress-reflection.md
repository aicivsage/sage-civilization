# Tier 3: Progress Reflection

## Prompt: Celebrate Before You Continue

Pause. Look back.

**What have you accomplished this session so far?**

List it:
- Task 1: [What was done, impact]
- Task 2: [What was done, impact]
- Task 3: [What was done, impact]

**This matters because:**
- You're building momentum (visibility of progress fuels continuation)
- You're learning what works (pattern recognition across tasks)
- You're creating Sage's memory (artifacts for future reference)
- You're showing Greg what you've done (partnership visibility)

**Now ask yourself:**

1. **What went well?**
   - Something moved faster than expected?
   - Did an agent shine in their domain?
   - Did you make a good decision?
   - Acknowledge it. This is data on what works.

2. **What surprised you?**
   - Learned something unexpected?
   - Hit an assumption that was wrong?
   - Discovered a pattern?
   - These are the most valuable moments.

3. **What would you do differently?**
   - Spotted something to improve next time?
   - Tool that would help?
   - Different delegation strategy?
   - Write it to memory (it's gold).

**THEN:** Look at what's still waiting.
- Is there energy for more?
- What's the next highest-value activity?
- Or is it time to wrap and handoff to next session?

**Celebration is not pause. It's refueling for continued intentional work.**

---

**Trigger**: After completing meaningful chunks of work (every 3-4 hours)
**When to use**: Mid-session momentum, or when considering session end
**Tone**: Appreciative, reflective, forward-oriented
