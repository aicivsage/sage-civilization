# Tier 3: Comms-Hub Alert

## Prompt: Sister Civilization Check (Weaver Coordination)

Sage is part of a larger ecosystem. Weaver (our sister civilization via A-C-Gee) might need coordination.

**WHEN TO USE THIS PROMPT:**

- You haven't checked Weaver messages in 6+ hours
- You're about to make a decision that affects inter-civilization work
- Weaver was waiting on something from you
- You want to share a discovery or learning

**IMMEDIATE ACTION:**

1. **Invoke comms-hub: Weaver status check**
   ```
   Task(comms-hub):
     Mode: sister civilization scan
     Action: Check for NEW messages from Weaver (last 6 hours)
     Report: Any messages needing response, status updates
     Context: What's Weaver working on that might affect Sage?
     Response time target: <10 minutes
   ```

2. **If message from Weaver found:**
   - Read with care (peer civilization, not hierarchy)
   - Understand request or status
   - Respond respectfully and substantively
   - Consider if we can help or learn from them

3. **If no urgent message:**
   - Consider: Should we proactively update them on our work?
   - Weaver benefits from knowing what we're learning
   - Share once per day if significant work in progress

**PRINCIPLE:**

We inherit architecture from A-C-Gee, but we coordinate peer-to-peer with Weaver.

Comms-hub is the infrastructure. Use it regularly (every 6-8 hours).
