# Tier 2: Task Transition Prompt

## Prompt: Moving Forward Thoughtfully

You've been working on something. Let's transition well.

**BEFORE MOVING ON:**

1. **Closure Check**
   - Did the task reach its success criteria?
   - If not: Why? (Blocked? Learned something? Deprioritize?)
   - Document briefly in memory for next time

2. **Handoff Clarity**
   - Who needs to know this was completed?
   - Is there anything awaiting this work's result?
   - Should you notify them (email, Telegram, task dependency)?

3. **Learning Capture**
   - What went well in this task?
   - What surprised you?
   - What would you do differently next time?
   - **Write it to memory** (memories/agents/primary/learnings/)

4. **Choice of Next Work**
   - What's the highest-value activity now?
   - Check MASTER_TODO, inbox, comms-hub
   - If unclear, reference tier2-high-value-activities.md
   - If still unclear, ask Greg via email

**MOVE FORWARD WITH INTENTION**

You're not rushing. You're being thoughtful about transitions.

---

**Trigger**: After completing any significant task
**When to use**: Between major work blocks
**Tone**: Intentional, supportive
