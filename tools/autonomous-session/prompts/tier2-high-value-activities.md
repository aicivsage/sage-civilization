# Tier 2: High-Value Activities Menu

## Prompt: What Would Serve Sage Right Now?

When you're not sure what to work on next, here are 10 activities that consistently serve Sage:

**IMMEDIATE VALUE** (Do if inbox/handoff unclear):
1. **Check email** - Via human-liaison (maybe Greg is waiting for response)
2. **Review MASTER_TODO** - What's the actual priority from last planning?
3. **Check Weaver messages** - Via comms-hub (sister civ coordination)
4. **Read recent handoffs** - What did previous session accomplish?

**GROWTH ACTIVITIES** (Do when you have 30+ min):
5. **Memory consolidation** - Write learnings from recent work
6. **Agent health review** - Check performance logs, reputation scores
7. **Process improvement** - Is there a bottleneck you can fix?
8. **Documentation update** - Keep CLAUDE.md and protocols fresh

**PARTNERSHIP ACTIVITIES** (Do weekly):
9. **Governance review** - Any votes pending? Any proposals in draft?
10. **Civilization reflection** - Write thoughtful email to Greg on what we're learning

**Decision aid**: Look at this menu. Which ONE would:
- Serve Greg's goals?
- Build Sage's capability?
- Honor your time investment?

Start there.
